# ВИАЙПИ РЕСТОБАР — приём предварительных заказов

Быстрый и элегантный веб-сервис для приёма броней и предзаказов: бланк на экране в точности как бумажный,
редактируемое меню, журнал заказов с миниатюрами бланков и печать / сохранение в PDF с логотипом.
Интерфейс — на русском, работает на телефоне, планшете и компьютере.

## Возможности

* **Меню** — добавить / изменить / удалить блюдо и категорию, поменять цену прямо в списке, «стоп-лист» (переключатель).
  Исходное меню ВИАЙПИ загружается автоматически при первом запуске.
* **Новый заказ (бланк)** — те же поля, что в бумажном бланке: Дата, ФИО, № телефона, Стол №, Кол-во гостей,
  Время заказа, Предоплата, таблица «Подача (время) / Наименование / Кол-во / Цена», Итого, Принял, Дата принятия.
  Плюс: примечания, комментарий к каждой позиции, автоподсчёт итога, предоплаты и остатка к доплате.
* **Печать / PDF** — бланк A4 с логотипом, аккуратный и ровный; сохраняется как PDF через окно печати. Бланк всегда помещается на **один лист**: если позиций много, он автоматически уменьшается.
* **Журнал** — все заказы с поиском, фильтрами (Сегодня / Ближайшие / Прошедшие), статусами и **миниатюрой бланка**;
  по клику открывается бланк целиком.
* **Онлайн** — данные хранятся в Firebase (Firestore), доступны на всех устройствах сразу, сохраняются и без сети.


## 1. Подключение Firebase (чтобы всё сохранялось онлайн)

Пока `js/firebase-config.js` пустой, приложение работает в **локальном режиме** (данные только в этом браузере) —
удобно, чтобы попробовать. Для работы онлайн сделайте один раз:

1. Откройте <https://console.firebase.google.com>. Можно взять **уже существующий проект**
   (например, от сайта заказа продуктов) или создать новый («Add project»).
2. **Build → Firestore Database → Create database** → режим *Production* → выберите ближайший регион.
3. Вкладка **Rules** → вставьте содержимое файла `firestore.rules`, **замените email** в списке на свои
   (строчными буквами) → **Publish**.
4. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save.**
   Затем вкладка **Users → Add user** — создайте логин и пароль для себя и сотрудников
   (эти же email должны быть в `firestore.rules`).
   *(Дополнительно: Settings → User actions → отключите «Enable create (sign-up)», чтобы никто не мог зарегистрироваться сам.)*
5. **Project settings (⚙) → Your apps → Web (`</>`)** → зарегистрируйте приложение → скопируйте блок
   `firebaseConfig` и вставьте значения в `js/firebase-config.js`.
6. *(Обычно не требуется)* Authentication → Settings → Authorized domains → добавьте `ВАШ-ЛОГИН.github.io`.

При открытии сайта появится экран входа — введите email и пароль из шага 4. Устройство запомнит вход.

## 2. Публикация на GitHub Pages

1. На GitHub: **New repository** (например, `vip-orders`) → **Add file → Upload files** → перетащите **всё содержимое папки**
   (файл `index.html` должен лежать в корне репозитория; папки `css`, `js`, `assets` — вместе с файлами) → **Commit changes**.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save.**
3. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/vip-orders/`.

Чтобы обновить сайт — загрузите изменённые файлы в репозиторий (замена файла = новая версия).
Всё, что вы меняете внутри приложения (меню, цены, заказы), хранится в Firebase и **не требует перезагрузки файлов**.

## 3. Как пользоваться

1. **Новый заказ** → введите ФИО гостя, дату, время, стол, гостей, предоплату.
2. Выберите блюда в меню справа (на телефоне — кнопка «Из меню»). Перед добавлением укажите **время подачи**
   (например, 21:30) — оно появится в колонке «Подача» рядом с блюдом, а строки в бланке упорядочатся по времени. Количество, цену и комментарий можно править в строке.
   «Своя позиция» — для блюда, которого нет в меню.
3. Укажите, кто принял заказ, и нажмите **«Сохранить и печать»** (или просто «Сохранить»).
4. В окне печати выберите принтер **«Сохранить как PDF»** (на компьютере) либо **«Печать» → «Сохранить в PDF»**
   (на Android / iPhone: «Поделиться → Печать»). Размер бумаги — A4, масштаб 100 %, «Колонтитулы» — выключить.
5. Позже все заказы находятся в **Журнале**: открыть, изменить, дублировать, сменить статус, снова распечатать.

## Полезно знать

* Цены в уже сохранённых заказах **не меняются** при изменении меню.
* Меню в фото не содержало напитков и кальянов — добавьте их в разделе **Меню → «+ Категория» / «+ Позиция»**.
* **Резервная копия:** значок профиля в правом верхнем углу → «Резервная копия (JSON)».
* Установка на телефон: в браузере «Добавить на главный экран» — приложение откроется как обычное.
* Если в индикаторе вверху «Нет доступа» — проверьте `firestore.rules` (email сотрудника в списке, правила опубликованы).
