# ВИАЙПИ РЕСТОБАР — приём предварительных заказов

Быстрый и элегантный веб-сервис для приёма броней и предзаказов: бланк на экране в точности как бумажный,
редактируемое меню, журнал заказов с миниатюрами бланков и печать / сохранение в PDF с логотипом.
Интерфейс — на русском, работает на телефоне, планшете и компьютере.

## Возможности

* **Меню** — добавить / изменить / удалить блюдо и категорию, поменять цену прямо в списке, «стоп-лист» (переключатель).
  Исходное меню ВИАЙПИ загружается автоматически при первом запуске.
* **Новый заказ (бланк)** — те же поля, что в бумажном бланке: Дата, ФИО, № телефона, Стол №, Кол-во гостей,
  Время заказа, Предоплата, таблица «Подача (время) / Наименование / Кол-во / Цена», Итого, Принял, Дата принятия.
  Плюс: примечания, комментарий к каждой позиции, автоподсчёт итога, предоплаты и остатка к доплате.
* **Печать / PDF** — бланк A4 с логотипом, аккуратный и ровный; сохраняется как PDF через окно печати. Бланк всегда помещается на **один лист**: если позиций много, он автоматически уменьшается.
* **Журнал** — все заказы с поиском, фильтрами (Сегодня / Ближайшие / Прошедшие), статусами и **миниатюрой бланка**;
  по клику на карточку открывается бланк целиком, по клику на **миниатюру** — крупный просмотр (см. «Увеличение бланка»).
* **Онлайн** — данные хранятся в Firebase (Firestore), доступны на всех устройствах сразу, сохраняются и без сети.

## 1. Подключение Firebase (чтобы всё сохранялось онлайн)

Пока `js/firebase-config.js` пустой, приложение работает в **локальном режиме** (данные только в этом браузере) —
удобно, чтобы попробовать. Для работы онлайн сделайте один раз:

1. Откройте <https://console.firebase.google.com>. Можно взять **уже существующий проект**
   (например, от сайта заказа продуктов) или создать новый («Add project»).
2. **Build → Firestore Database → Create database** → режим *Production* → выберите ближайший регион.
3. Вкладка **Rules** → вставьте содержимое файла `firestore.rules`, **замените email** в списке на свои
   (строчными буквами) → **Publish**.
4. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save.**
   Затем вкладка **Users → Add user** — создайте логин и пароль для себя и сотрудников
   (эти же email должны быть в `firestore.rules`).
   *(Не отключайте Settings → User actions → «Enable create (sign-up)» — через него приложение создаёт аккаунты официантов. Безопасность обеспечивают правила базы, а не закрытая регистрация.)*
5. **Project settings (⚙) → Your apps → Web (`</>`)** → зарегистрируйте приложение → скопируйте блок
   `firebaseConfig` и вставьте значения в `js/firebase-config.js`.
6. *(Обычно не требуется)* Authentication → Settings → Authorized domains → добавьте `ВАШ-ЛОГИН.github.io`.

При открытии сайта появится экран входа — введите email и пароль из шага 4. Устройство запомнит вход.

## 2. Публикация на GitHub Pages

1. На GitHub: **New repository** (например, `vip-orders`) → **Add file → Upload files** → перетащите **всё содержимое папки**
   (файл `index.html` должен лежать в корне репозитория; папки `css`, `js`, `assets` — вместе с файлами) → **Commit changes**.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save.**
3. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/vip-orders/`.

Чтобы обновить сайт — загрузите изменённые файлы в репозиторий (замена файла = новая версия).
Всё, что вы меняете внутри приложения (меню, цены, заказы), хранится в Firebase и **не требует перезагрузки файлов**.

## 3. Как пользоваться

1. **Новый заказ** → введите ФИО гостя, дату, время, стол, гостей, предоплату.
2. Выберите блюда в меню справа (на телефоне — кнопка «Из меню»). Перед добавлением укажите **время подачи**
   (например, 21:30) — оно появится в колонке «Подача» рядом с блюдом. Время можно задать **прямо в строке блюда в меню** (поле между названием и ценой) — тогда блюдо добавится сразу со своим временем (если нажали «+» без времени — просто впишите время в той же строке меню, оно проставится в заказ); «Общее время подачи» сверху подставляется блюдам, у которых своё время не задано. Время вводится цифрами: `1930` → 19:30, `9` → 09:00 (24 часа, без AM/PM). Строки в форме **не прыгают** сами; кнопка «По времени» расставляет их по времени, а при сохранении, печати и отправке картинкой бланк всегда упорядочен по времени. Количество, цену и комментарий можно править в строке. Внизу формы — кнопка **«Удалить этот бланк»** (для нового бланка стирает и черновик) или **«Удалить заказ»** (при редактировании сохранённого).
   «Своя позиция» — для блюда, которого нет в меню.
3. Укажите, кто принял заказ, и нажмите **«Сохранить и печать»** (или просто «Сохранить»).
4. В окне печати выберите принтер **«Сохранить как PDF»** (на компьютере) либо **«Печать» → «Сохранить в PDF»**
   (на Android / iPhone: «Поделиться → Печать»). Размер бумаги — A4, масштаб 100 %, «Колонтитулы» — выключить.
5. Позже все заказы находятся в **Журнале**: открыть, изменить, дублировать, сменить статус, снова распечатать.

## Полезно знать

* Цены в уже сохранённых заказах **не меняются** при изменении меню.
* Меню в фото не содержало напитков и кальянов — добавьте их в разделе **Меню → «+ Категория» / «+ Позиция»**.
* **Резервная копия:** значок профиля в правом верхнем углу → «Резервная копия (JSON)».
* Установка на телефон: в браузере «Добавить на главный экран» — приложение откроется как обычное.
* Если в индикаторе вверху «Нет доступа» — проверьте `firestore.rules` (email сотрудника в списке, правила опубликованы).

## Напитки в меню

Барное меню (кофе, милкшейки, напитки, безалкогольные коктейли, чай и добавки — 34 позиции, 6 категорий)
загружается автоматически **один раз**: и в новую, и в уже работающую базу. Ваши правки не перезаписываются,
а удалённые позиции не возвращаются. Дальше всё меняется в разделе «Меню».

## Поделиться бланком картинкой (WhatsApp, Telegram, ВК)

Откройте заказ в журнале и нажмите **«Поделиться»**:

* на телефоне — кнопка «Поделиться…» открывает системное меню, выберите WhatsApp, Telegram или ВК: бланк уйдёт картинкой (PNG, формат A4);
* на компьютере — «Скачать PNG» или «Копировать», затем кнопки WhatsApp / Telegram / ВКонтакте откроют веб-версию мессенджера;
  изображение уже в буфере обмена — в чате нажмите ⌘V (Ctrl+V).

Если позиций очень много, картинка автоматически становится чуть длиннее листа, чтобы текст оставался читаемым.

## Позиции без времени подачи

Чтобы ни одно блюдо не ушло в бланк без времени:

- строка без времени в заказе подсвечена **янтарным** цветом, а над списком появляется счётчик **«Без времени: N»** — нажмите на него, и курсор встанет в первое пустое поле;
- в меню у блюда без времени строка «в заказе: без времени» тоже янтарная;
- при нажатии **«Сохранить»** (или «Печать») приложение покажет окно со списком позиций без времени: можно **указать время**, поставить **одно время всем** («Проставить и сохранить») или сохранить как есть;
- если заказ всё же сохранён без времени, на его странице есть жёлтая плашка с кнопкой «Указать время», а в журнале у карточки — пометка «без времени: N»;
- клавиша **Enter** в поле времени фиксирует время и закрывает клавиатуру.

## Официанты (только просмотр)

Официанты видят **заказы и печатную форму**, но не могут создавать, менять и удалять заказы, открывать меню и настройки.
У каждого свой логин и пароль, аккаунты создаёт и отключает руководитель прямо в приложении.

**Один раз** обновите правила: Firebase → Firestore Database → Rules → вставьте новый `firestore.rules` (email персонала в списке оставьте свой) → **Publish**.
Вход по Email/паролю должен оставаться включённым (шаг 4).

Как добавить официанта:
1. Войдите как руководитель → значок человека справа вверху → **«Официанты (просмотр)»** → **«Добавить официанта»**.
2. Введите имя. Логин подставится сам (латиницей, можно изменить). Пароль можно придумать или нажать «Сгенерировать» — приложение предложит надёжный пароль.
3. После создания появится карточка с логином и паролем — **пароль показывается один раз**, скопируйте или отправьте его официанту (кнопки «Копировать» / «Отправить»).

Официант открывает тот же сайт и входит по **логину и паролю** (не email). Он видит журнал и страницу заказа, может **увеличить бланк, скачать или отправить его картинкой**, нажать «Печать / PDF» и сменить свой пароль (меню профиля → «Сменить пароль»).

Управление:
- **Пауза** («Отключить доступ») — аккаунт отключается сразу, даже если официант сейчас в приложении (его выкидывает на экран «Нет доступа»); кнопка **Play** («Включить доступ») возвращает доступ.
- **Корзина** («Удалить») — удаляет доступ. Логин можно создать заново (с тем же или новым паролем).
- Забыл пароль — создайте для него новый логин (старый удалите), либо удалите пользователя в Firebase → Authentication → Users.

Важно знать:
- Пароли нигде не хранятся в приложении и в коде. Логин `ivan` внутри Firebase превращается в служебный адрес `ivan@waiter.vip` (письма на него не отправляются).
- Права проверяет **сама база** (правила), а не интерфейс: даже если взломать страницу, официант не сможет записать или удалить данные.
- После удаления официанта запись в Firebase → Authentication → Users остаётся (без доступа ни к чему) — при желании удалите её там вручную.
- В локальном режиме (без Firebase) официантов нет.

## Увеличение бланка

Нажмите на **миниатюру** в журнале или на **бланк** на странице заказа (есть и кнопка «Увеличить») — откроется полноэкранный просмотр.
Текст рисуется векторно, поэтому остаётся чётким при любом приближении.

- **Телефон:** двойное касание — приблизить / вписать, два пальца — масштаб, один палец — двигать; кнопка «Назад» закрывает окно.
- **Компьютер:** колесо мыши (или Ctrl + колесо), двойной клик, перетаскивание; клавиши `+` `−` `0` и стрелки; `Esc` закрывает.
- Внизу — **«Скачать»** (PNG) и **«Поделиться»** (WhatsApp, Telegram, ВК и др. — картинкой). Эти кнопки доступны и официантам.
  Из журнала есть ещё кнопка «Открыть заказ».

## Работа без VPN (Россия)

Приложение состоит из двух частей: **сайт** (GitHub Pages) и **база данных** (Google Firebase). Что сделано, чтобы оно работало без VPN:

- **Офлайн-кэш (`sw.js`).** После первого успешного открытия приложение и библиотека Firebase сохраняются на устройстве.
  Дальше оно запускается мгновенно и **даже без интернета**: видны заказы, можно создавать и менять — всё отправится в облако, когда связь появится.
- **Шрифты Google грузятся фоном.** Если они недоступны, страница не ждёт их, а открывается сразу на запасных шрифтах.
- **Запасной режим соединения.** Если оператор ломает потоковое соединение с Firestore, библиотека переключается на обычные запросы.
- **Понятные сообщения.** Индикатор вверху показывает «Нет связи», если интернет есть, а сервер Google не отвечает; при долгом старте появляется ссылка «Проверить связь».
- **Страница «Проверка связи»:** `ВАШ-САЙТ/net-check.html`. Откройте её на телефоне **с выключенным VPN** — она за несколько секунд покажет, что именно
  доступно (сайт, библиотека Firebase, база, вход, шрифты) и сравнит с Яндексом. Кнопка «Скопировать отчёт» — чтобы переслать результат.

**Важно знать.** Первое открытие приложения на новом устройстве требует рабочей связи с `gstatic.com` и `*.googleapis.com`. Если оператор их полностью блокирует
(в некоторых регионах действуют «белые списки»), без VPN база данных недоступна — тогда единственное полное решение: перенести базу на российский сервер.
Результат «Проверки связи» покажет, нужно ли это именно вам.

## Автоудаление старых заказов

Заказ хранится в журнале до **даты заказа + 3 дня включительно**, а на следующий день удаляется автоматически
(пример: заказ на 20-е виден до 23-го, 24-го его уже нет). Срок меняется в меню профиля (значок человека справа вверху → «Автоудаление») или нажатием на пометку над списком заказов; **0 — не удалять**. Настройка общая для всех устройств.

Как это сделано надёжно:
- «Сегодня» берётся из времени сервера (заголовок `Date` ответа сайта), а не из часов телефона — неверная дата на устройстве ничего не удалит. Нет ответа сервера — ничего не удаляется.
- Чистка выполняется при открытии приложения (на любом телефоне/компьютере) и раз в сутки, пока оно открыто. Заказ, который открыт в этот момент, пропускается.
- Если сразу набирается больше 8 заказов на удаление — приложение спросит подтверждение. После удаления показывается уведомление.
- Заказы без даты не удаляются. Перед важной чисткой можно скачать «Резервная копия (JSON)» в меню профиля.
- На странице заказа внизу указана дата автоудаления.

## Обновления приложения

Внизу меню профиля написан номер версии (например, `2026-11-27c`). Когда вы загружаете новую версию на GitHub, открытое приложение само покажет плашку **«Вышла новая версия — Обновить»**.
При обновлении файлов загружайте также `version.json` и меняйте в нём номер так же, как `APP_VERSION` в `js/app.js`, `VERSION` в `sw.js` и `?v=` в `index.html`.
